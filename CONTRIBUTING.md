# Contributing to AlertView

Bug reports, ideas and pull requests are welcome.

- **A bug or an idea**: open an [issue](https://github.com/frakev/alertview/issues)
  with the AlertView version, what you expected, what happened, and the
  relevant part of your configuration **without tokens**.
- **A security problem**: see [SECURITY.md](SECURITY.md) — not a public issue.
- **Code**: how to build, test and check your change before opening a pull
  request is in [docs/development.md](docs/development.md).
